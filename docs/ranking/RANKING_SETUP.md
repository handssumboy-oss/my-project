# 랭킹 서버 연결하기 (구글 시트 + Apps Script)

게임은 서버가 없는 GitHub Pages 사이트입니다. 여러 사람의 점수를 한곳에 모으기 위해 **구글 시트를 랭킹 저장소로** 쓰고, 시트에 붙인 **Apps Script 웹 앱**이 점수 등록·순위 조회를 처리합니다. 설정 전에는 게임이 **이 기기 랭킹**(같은 휴대폰 안의 기록끼리 순위)으로 동작하므로 서비스에는 문제가 없습니다.

약 10분이면 끝납니다.

## 1. 시트 만들기

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만들고 이름을 `자봉이 랭킹` 등으로 바꿉니다.
2. 시트 탭은 그대로 두면 됩니다. 처음 점수가 들어올 때 스크립트가 `랭킹` 탭과 머리글(시간·닉네임·소속·점수…)을 자동으로 만듭니다.

## 2. 스크립트 붙여 넣기

1. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 저장소의 [`docs/ranking/apps-script.gs`](./apps-script.gs) 파일 내용을 **전부** 붙여 넣습니다.
3. 💾 저장을 누릅니다.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 설명: `자봉이 랭킹 v1`
   - **실행 사용자: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포**를 누르고, 권한 요청 화면에서 본인 계정으로 **액세스 허용**을 누릅니다. ("확인되지 않은 앱" 안내가 나오면 **고급 → (프로젝트 이름)으로 이동**을 누릅니다. 내가 만든 스크립트라서 나오는 안내입니다.)
5. 나타난 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 기관(Google Workspace) 계정에서 "모든 사용자"가 보이지 않으면 관리자 정책으로 익명 접근이 막혀 있는 것입니다. 전산 담당자에게 허용을 요청하거나, 랭킹 전용 개인 구글 계정으로 시트를 만들어 주세요.

## 4. 게임에 URL 넣기

`src/ranking-config.js`의 따옴표 안에 URL을 붙여 넣고 main 브랜치에 반영하면, GitHub Pages 배포 후 바로 **LIVE RANKING**으로 바뀝니다.

```js
export const RANKING_ENDPOINT = 'https://script.google.com/macros/s/여기에-복사한-값/exec';
```

URL을 Claude에게 알려 주면 대신 넣고 테스트해 드릴 수도 있습니다.

## 5. 운영하기

| 할 일 | 방법 |
|---|---|
| 부적절한 기록 숨기기 | `랭킹` 탭에서 해당 행의 **숨김** 열을 `TRUE`로 바꿉니다. 즉시 순위에서 빠집니다. |
| 시즌 초기화 | 기존 탭 이름을 `랭킹_2026가을` 등으로 바꾸면 새 `랭킹` 탭이 자동 생성됩니다. 지난 기록은 보관됩니다. |
| 스크립트를 고친 뒤 | **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**. URL은 바뀌지 않습니다. |

## 자동으로 걸러지는 것

- 닉네임 2~8자, 소속 최대 12자. 욕설·비속어, 전화번호·이메일·주소처럼 보이는 입력은 등록되지 않습니다(브라우저와 스크립트 양쪽에서 검사).
- `=`, `+`, `-`, `@`로 시작하는 입력은 시트 수식으로 실행되지 않도록 앞 글자를 지웁니다.
- 같은 기기에서는 20초에 한 번만 등록됩니다. 점수는 0~12,000점만 받습니다.

## 알아 두실 점

- **개인정보:** 화면에서 "실명·전화번호·학교 반을 쓰지 말라"고 안내하며, 시트에는 닉네임·소속·점수·플레이 기록과 무작위 **기기 ID**(같은 기기 연속 등록 제한용, 개인 식별 정보 아님)만 저장됩니다. 청소년 참여가 많으면 행사 종료 후 시트를 정리(삭제)하는 운영 원칙을 정해 두기를 권합니다.
- **점수 조작:** 점수는 플레이어의 브라우저가 계산해 보내므로, 기술적으로 작정하고 조작하는 사람을 완전히 막을 수는 없습니다. 상품이 걸린 이벤트라면 상위 기록을 시트에서 확인(플레이 시간·보스 정화 수 등)한 뒤 시상하는 방식을 권합니다.
- **소속 순위:** 소속별로 구성원 각자의 최고 기록 중 **상위 5명의 합계**로 매깁니다. 소속 이름이 한 글자라도 다르면 다른 소속으로 집계되니, 행사 안내에 정확한 소속 표기를 적어 두면 좋습니다.
- 점수 규칙(`src/ranking-core.js`)을 바꾸면 `npm run ranking:sync`로 `apps-script.gs`의 규칙 부분을 다시 만들고, 시트의 스크립트도 새로 붙여 넣어 재배포하세요. 테스트(`tests/ranking-core.test.js`)가 두 파일이 같은지 검사합니다.
