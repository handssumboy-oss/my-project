# 공식 자봉이 이미지

공식 PNG/WebP 파일을 이 폴더에 넣고 `src/config.js`의 `CHARACTER_PATH`를 파일명으로 지정합니다.
예: `export const CHARACTER_PATH = 'jabongi.png';`

원본은 편집하지 않으며 CSS `object-fit: contain`과 원본 종횡비로 표시합니다.
현재 공식 이미지가 없는 경우에만 임시 기본 도형을 표시합니다. 임시 도형은 자봉이의 공식 디자인이 아닙니다.
투명 배경 PNG/WebP를 권장합니다. 이미지 저작권 및 사용 권한은 원 권리자에게 있습니다.

## 업로드된 파일

GitHub main 커밋 `22a877f`에서 받은 PNG 원본 12개를 `jabongi-01.png`~`jabongi-12.png`로 복사했습니다. 파일 바이트는 변경하지 않았습니다. `sources.json`에서 원본 파일명 대응을 확인할 수 있습니다. 초기 적용은 `jabongi-10.png`의 점프 포즈를 사용했으며, 현재 적용 파일은 아래 투명도 정리 버전을 참고하세요.

## 러너용 파생 파일

`jabongi-runner.png`: `jabongi-10.png`의 흰 배경을 Image Gen으로 제거한 투명 PNG. 캐릭터 디자인·비율을 유지하도록 요청했으며 원본은 그대로 보관합니다. 러너 시작 화면, 플레이 스프라이트, 결과 PNG에서 사용합니다.

## 투명도 정리 버전

현재 러너와 미션 모드 모두 `jabongi-clean.png`를 사용합니다. Image Gen으로 기존 투명 파생 파일의 외곽 배경·흰 잔여물을 정리한 RGBA 파일이며 1122×1402 원본 프레이밍을 유지합니다. 저장소에 업로드된 원본 12개는 RGB 파일로 알파 채널이 없고, 일부 체크무늬도 픽셀에 포함되어 있습니다. 원본 파일과 이전 파생 파일은 보관합니다. CSS에는 캐릭터 이미지의 흰 배경·사각형 그림자를 적용하지 않습니다.
