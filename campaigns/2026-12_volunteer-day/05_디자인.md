## 1. 디자인 원칙

### 1-1. 10/23 시리즈와 이어지게
- 10/23 `cards.html`의 구조를 **그대로** 씁니다. 크림 바탕, 차콜 글씨, 남색 강조, 지구본 선 그림, 왼쪽 정렬 제목, 오른쪽 아래 페이지 표시입니다. 보는 사람이 "10월에 본 그 시리즈의 마지막 편"으로 알아볼 수 있게 합니다.
- 바뀌는 것은 **문구와 장 수뿐**입니다. 새 색, 새 서체, 사진, 새 일러스트 양식을 더하지 않습니다.
- 지구본 선 그림은 표지와 마지막 장에만 둡니다(10/23과 같은 위치·투명도). 가운데 장에는 장식을 두지 않습니다.
- 표현 금지: 컨페티·폭죽·반짝이·풍선·트로피·선물 상자·하트 스티커, 이모지, 느낌표, "축하"·"이벤트"·"경품"·"선물", 재촉 표현("서두르세요", "놓치지 마세요", "마지막 기회", "N시간 남음"), **1365 포털 명칭·가입 권유**, 개인정보 관련 사건·추모 사안 직접 언급.
- 어조: 차분한 감사입니다. 성과를 자랑하기보다 "함께해 주셔서 고맙습니다"로 마무리합니다. 동정심을 자극하는 표현은 쓰지 않습니다(전략 5장).

### 1-2. 색 (10/23 `cards.html` `:root` 값 그대로)

| 이름 | HEX | 용도 | 크림 위 대비(참고 계산값) |
|---|---|---|---|
| 크림 | `#FFF8EE` | 모든 장 배경 | - |
| 차콜 | `#2B2B2B` | 제목·본문 | 약 13:1 |

| 남색 | `#1F3A5F` | 라벨·강조 숫자·번호 원·날짜 상자·배지 | 약 11:1 (남색 위 흰 글씨 약 11.5:1) |
| 흰색 | `#FFFFFF` | 목표·수치 상자 면, 감사 템플릿 쓰기 칸 | 차콜과 약 15:1 |

- 붉은색·노랑·그라데이션·형광색은 쓰지 않습니다.
- 위 대비는 참고 계산값입니다. 제작 후 [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)로 다시 확인합니다. 기준은 본문 4.5:1, 큰 제목 3:1 이상(WCAG 2.1 AA)입니다.
- 지구본 선 그림은 투명도 0.45~0.55의 장식입니다. **글자를 지구본 위에 겹치지 않습니다.**

### 1-3. 서체·글자 크기
- Noto Sans KR(SIL OFL) 400·500·700·900, 10/23과 같습니다. Canva로 만들 때도 Noto Sans KR을 씁니다(Pretendard로 바꾸지 않음, 시리즈 통일).
- 크기(1080px 너비 캔버스 기준, 이 문서의 pt = Canva 1080px 캔버스의 글자 크기 값 = `cards.html`의 px)

| 요소 | 크기·굵기 | `cards.html` 클래스 |
|---|---|---|
| 표지 제목 | 80pt / 900 | `h1` |
| 장 제목 | 66pt / 900 | `h2` |
| 본문(리드) | 40pt / 500, 줄 간격 155% | `.lead` |
| 보조 | 34pt / 500 | `.sub` |

- **어떤 글자도 26pt 밑으로 줄이지 않습니다.** 문장이 넘치면 글자를 줄이지 말고 문장을 줄입니다.
- 색만으로 정보를 구분하지 않습니다. 강조는 굵기·상자·번호로 합니다.

### 1-4. 로고·엠블럼
- 10/23처럼 **표지 상단(왼쪽 세계 자원봉사자의 해 엠블럼, 오른쪽 기관 CI)과 마지막 장 하단**에만 넣습니다.

- 원본 사용 규정을 따릅니다. 색·비율 변형, 그림자·외곽선, 잘라내기, 투명도 조정, 확대를 하지 않습니다. 크림 배경 위에 바로 두어도 되는지도 규정으로 확인합니다 `[브랜드 가이드 확인 필요]`.

### 1-5. 사진·인물
- **사진과 인물 그림을 쓰지 않습니다**(10/23과 같음). 감사 캠페인이라도 자원봉사자·수혜자 사진, 현장 사진, AI 생성 인물 이미지를 넣지 않습니다.
- 나중에 사진이 필요해지면(12/6 이후 결산 영상 등) 전략 5장을 따릅니다. 자원봉사자는 게시 동의를 받고 기록을 남기며, 수혜자·아동은 동의와 관계없이 식별되지 않게 합니다.

- 이름·얼굴·사진 없이 **한 줄 문구만** 쓰도록 이미지 안에서 안내합니다. 다른 사람(함께한 분, 도움을 받은 분)의 이름·얼굴·사는 곳·기관명도 적지 않도록 안내합니다.
- **기관 계정 태그, 해시태그, '함께해요(Add Yours)' 스티커는 기본으로 쓰지 않습니다.** 태그나 스티커를 쓰면 참여한 계정 목록이 기관 쪽에 모이거나 공개됩니다. KPI(해시태그 게시물 수) 때문에 해시태그를 쓰기로 하면 리더가 판단하고, 이미지가 아니라 캡션에서만 안내합니다 `[확인 필요: 공식 해시태그, 리더 판단]`.
- **기관이 참여자 스토리를 다시 올리지(리그램) 않는 것을 기본으로 합니다.** 다시 올리려면 계정마다 본인 동의를 받아야 하고 계정 이름이 드러나기 때문입니다. 필요하면 리더 승인 후 별도 절차로 정합니다.
- 이 방식은 '이벤트'가 아니라 '감사 인사 나누기'입니다. 캡션에도 "이벤트"·"참여하면"·"선물"을 쓰지 않습니다.

## 6. `cards.html` 재사용 방법

10/23 폴더는 **건드리지 않고 복사해서** 씁니다. 이번 작업에서는 아래 파일을 만들지 않았습니다. 제작 담당이 문서 검토 후 진행합니다.

1. **복사:** `campaigns/2026-10_un-day/`의 `cards.html`, `fonts_subset.py`, `render.js`, `logo_ivy_t.png`, `logo_kvc_t.png`를 `campaigns/2026-12_volunteer-day/design/`(새 하위 폴더 제안)으로 복사합니다. `fonts/`와 `fonts.css`는 다시 만들어지므로 복사하지 않아도 됩니다(빈 `fonts/` 폴더는 만들어 둡니다).
2. **문구만 교체:** 복사본 `cards.html`에서 각 `<section class="card">` 안의 글자만 2장 구성안대로 바꿉니다. `<style>`의 색·크기 값은 바꾸지 않습니다.
   - 6장이므로 c5 블록을 복사해 `id="c6"`을 하나 더 만들고, 페이지 표시를 모두 "n / 6"으로 고칩니다.
   - 1/6의 "고맙습니다,"만 남색으로 하려면 `<span style="color:#1F3A5F">`로 감쌉니다(새 클래스 추가 불필요).
   - 5/6은 c3 블록에서 `.goals`를 지우고 `.lead`만 남기는 식으로 만듭니다.
3. **`render.js` 두 곳 수정(복사본만):** 반복 횟수 `i <= 5` → `i <= 6`, 파일명 `un_card_${i}.png` → `vday_card_${i}.png`
4. **스토리(3장·4장)를 HTML로 만들 경우:** `stories.html`을 따로 만들고 `.card`의 크기를 `width:1080px; height:1920px`로 둡니다. `render.js` 복사본은 viewport 높이를 1980 이상으로 올리고 `stories.html`의 각 섹션을 차례로 저장하게 고칩니다. `fonts_subset.py` 복사본은 `cards.html`만 읽으므로, `stories.html`의 글자도 함께 읽도록 파일 목록을 늘립니다. 그러지 않으면 스토리에만 있는 글자가 기본 서체로 깨져 나옵니다. Canva로 만든다면 이 단계는 필요 없습니다.
5. **다시 만들기:** 복사한 폴더에서 `python3 fonts_subset.py && NODE_PATH=$(npm root -g) node render.js`
   - `fonts_subset.py`는 Google Fonts에서 쓰인 글자만 받아 오므로 **인터넷 연결이 필요합니다.** 문구를 한 글자라도 바꾸면 반드시 다시 실행합니다.
   - `render.js` 실행 결과에 `loaded fonts: Noto Sans KR`이 찍히는지 확인합니다.
6. **로고 교체:** 게시본을 만들기 전에 `logo_*_t.png`를 고해상도 원본으로 바꾸고, `.logos .ivy` / `.logos .kvc`의 높이는 규정에 맞춥니다 `[브랜드 가이드 확인 필요]`.
