## 0. 공통 원칙

### 0-1. 어조·표현
- **차분한 버전.** 컨페티·폭죽·반짝이·단풍잎 흩뿌림, 트로피·메달·선물 상자 아이콘, 형광 스티커, 이모지, 느낌표를 쓰지 않는다.
- 재촉 표현("서두르세요", "마지막 기회", "놓치지 마세요", "N시간 남음")을 쓰지 않는다. 근거: 전략 5장, `03_보도.md` 원칙 표.
- **시상·상품:** 이미지에 상품권·금액·상품 종류("온누리상품권" 등), 부문명(마스터·시그니처·베스트), "상금", "경품"을 쓰지 않는다. 시상 건수도 **이미지에서는 생략을 권장**한다. 꼭 넣어야 하면 4/5 보조 문구 자리에 "총 26건 시상 예정"만 한 줄로 두고, 공고문 원문 대조 전에는 넣지 않는다 `[확인 필요: 시상 건수 원문]`.
- **개인정보:** 회원가입·로그인 방식, 동의 항목, "개인정보는 안전하게 관리합니다" 같은 단정·다짐 문구를 이미지에 넣지 않는다. 응모 절차의 세부는 "누리집 공고에서 확인해 주세요"로만 안내한다 `[확인 필요: 로그인 방식(누리집 회원가입/SNS 로그인), 동의 항목]`.
- 사건·국정감사·포털 명칭은 언급하지 않는다. 1365 포털 표기·가입 권유도 넣지 않는다.
- 마감 시각은 원문에서 확인되지 않았으므로 쓰지 않는다 `[확인 필요: 마감 시각]`. 날짜는 "10월 25일(일)까지"만 쓴다.

- 기관 CI와 2026 세계 자원봉사자의 해 엠블럼은 **원본 파일만** 쓰고 색·비율 변형, 그림자·외곽선 효과, 잘라내기, 배경 위 투명도 조정을 하지 않는다. 여백·최소 크기·병기 순서는 공식 규정을 따른다 `[브랜드 가이드 확인 필요]`.
- 「모두의 봉사 레시피」 캠페인 로고(또는 AWARDS 전용 로고)가 있으면 원본과 사용 규정을 받아 쓴다. 없으면 텍스트 표기로만 둔다 `[브랜드 가이드 확인 필요: 캠페인 로고 유무·사용 규정]`.
- `hip/assets/logo_*_t.png` 같은 잘라 쓴 임시 소스는 쓰지 않는다.
- 로고는 흰 띠 위에만 둔다(크림 배경 위 직접 배치는 규정 확인 후).

### 0-5. 사진·일러스트 사용 기준
- **기본은 사진 없이 선 일러스트만 쓴다.** 이번 마감 안내 세트(1·2장)에는 사진 자리를 두지 않는다.
- 사람을 그릴 때는 **얼굴 없는 단순한 선 실루엣**만. 어르신·아동을 특정하는 소품(지팡이, 휠체어, 책가방 등)과 쓸쓸하거나 동정심을 자극하는 묘사는 쓰지 않는다(10/6 B안 기준).
- 배경은 공원·산책로·나무까지. **장터·행사장·물건 상자, 도로·골목·차량 그림은 쓰지 않는다**(10/5·10/6 검수 지적, 녹색장터 연상 방지).
- 나중에 사진을 써야 할 경우(예: 결과 안내, 보도자료 첨부)
  - 참여자·자원봉사자: 얼굴이 식별되는 사진은 **본인의 게시 동의**가 확인된 경우에만. 동의 기록(누가, 언제, 어떤 채널·용도로)을 남긴다.
  - 수혜자·아동: **동의 여부와 관계없이 식별되지 않게** 한다(뒷모습, 손, 원거리, 흐림 처리). 이름표·교복·학교명·차량 번호·집 주소가 보이는 요소도 지운다.
  - 응모작 사진은 콘텐츠 활용 동의 범위 안에서만 쓴다 `[확인 필요: 공고문 콘텐츠 활용 동의 범위]`. 이번 세트에는 쓰지 않는다.
- AI 생성 인물 이미지는 실제 참여 사진으로 오인될 수 있어 쓰지 않는다.

### 0-6. 이미지 출처·라이선스 주의
- 아이콘·일러스트·사진은 출처와 라이선스를 제작 파일 메모(또는 별도 표)에 기록한다: 파일명 / 출처 URL / 라이선스 종류 / 상업·공공기관 SNS 사용 가능 여부 / 출처 표기 의무.
- Canva 요소는 무료·Pro 여부와 Canva 콘텐츠 라이선스 조건을 확인한다. 공공누리 자료는 유형(1~4유형)에 따라 변경 금지·출처 표기 의무를 지킨다.
- 다른 기관·기업 로고(포털·SNS 플랫폼 로고 등), 타 캠페인 이미지, 검색으로 내려받은 이미지는 쓰지 않는다.
- 아이콘은 한 세트(같은 선 굵기·같은 제작자)로 통일한다. 아이콘 세트 라이선스 `[확인 필요]`.

## 1. AWARDS 마감 안내 카드뉴스 (인스타그램 피드 1080×1350, 5장)

- **공통 레이아웃**
  - 배경 크림 단색. 안전 영역 상하좌우 80px.
  - 상단 라벨(y=80~140): "2026 모두의 봉사 레시피 AWARDS" 회색 26pt, 왼쪽.
  - 본문 영역(y=180~1180): 각 장의 '레시피 카드' — 흰 면 920px 폭, 연회색 2px 테두리, 모서리 라운드 16px. 카드 안에 필요한 장만 "재료 / 방법" 두 칸.

  - 장식: 장마다 가는 남색 선 일러스트 1개 이하(선 굵기 3px).
