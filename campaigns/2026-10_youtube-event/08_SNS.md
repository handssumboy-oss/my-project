```
[당첨자 발표] '행복합니다' M/V 댓글 이벤트에 참여해 주신 모든 분께 감사드립니다.
당첨자께는 응모 시 입력하신 연락처로 경품을 순차 발송합니다(최대 2주 소요).
자세한 내용: https://ivy2026korea.or.kr/event/read/17
```

- 참여 댓글을 발표 게시물에 인용하려면 작성자 동의가 필요하다. 동의 없이 쓸 경우에는 계정명 없이 "가장 많이 나온 행복의 순간" 같은 **주제 요약**(예: 산책, 가족과의 식사 등 실제 집계 결과 `[확인 필요]`)만 쓴다.

## 7. 측정 지표와 단계별 이탈률 확인 방법

### 7-1. 참여 퍼널과 데이터 출처

| 단계 | 지표 | 데이터 출처 |
|---|---|---|
| 0. 도달 | M/V 조회수, 채널별 게시물 도달·링크 클릭 | YouTube 스튜디오(영상 분석), 인스타그램·페이스북 인사이트, 카카오톡 채널 통계 |
| 1. 구독 | 기간 내 구독자 순증, M/V를 통한 구독 획득 수 | YouTube 스튜디오 > 분석 > 구독자(기간: 9/30~10/14), 영상별 '구독자' 지표 |
| 2. 좋아요·댓글 | M/V 좋아요 수, **최상위 댓글 작성 고유 계정 수** | YouTube 스튜디오 댓글 목록, 필요 시 YouTube Data API로 기간 내 댓글 추출 `[확인 필요: 담당·도구]` |
| 3. 인증 | 구글폼 제출 수(전체 / 중복 제외 / 유효) | 구글폼 응답 시트 |
| 결과 | 유효 응모 수, 발표 후 구독 취소 추이 | 검수 결과, YouTube 스튜디오 구독자 감소 |

- 댓글 수 집계 시 제외: 운영자 계정 댓글·답글, 참여와 무관한 댓글, 같은 계정의 중복 댓글. 답글 인정 여부(0장 2번)에 따라 답글 포함 여부를 정한다.
- 폼 응답 시트는 개인정보가 들어 있으므로 지표 집계용으로는 **건수만** 뽑아 쓰고, 연락처 열은 열람·복사하지 않는다. 시트 접근 권한은 담당자로 제한한다 `[확인 필요]`.

### 7-2. 이탈률 계산

| 지표 | 계산식 | 의미 |
|---|---|---|
| 댓글 전환율 | 고유 댓글 작성 계정 수 ÷ 기간 내 M/V 조회수 | 영상 시청 후 댓글까지 오는 비율 |
| **3단계 이탈률(핵심)** | 1 − (중복 제외 폼 제출 수 ÷ 고유 댓글 작성 계정 수) | 댓글만 쓰고 인증을 안 한 비율 |
| 인증 유효율 | 유효 응모 수 ÷ 중복 제외 폼 제출 수 | 캡처 불량(계정명·댓글 누락) 등으로 탈락한 비율 → 안내 문구 개선 근거 |
| 구독 연결률 | 기간 내 구독자 순증 ÷ 고유 댓글 작성 계정 수 | 참고 지표. 기존 구독자도 참여하므로 1단계 이탈률로 직접 해석하지 않는다 |
| 발표 후 유지율 | 1 − (10/16~10/30 구독 취소 수 ÷ 기간 내 신규 구독 수) | 이벤트로 늘어난 구독자가 남는지 확인 |

- 구독 여부는 개인 단위로 Studio에서 확인할 수 없으므로, 1단계 이탈은 검수 단계에서 표본 확인으로만 추정한다 `[확인 필요: 구독 확인 방법]`.

### 7-3. 점검 일정과 조치

| 시점 | 점검 | 조치 기준(예시) |
|---|---|---|
| 매일 오전 | 댓글 수, 폼 제출 수, 검토 대기 댓글 | 폼 제출이 댓글 증가를 따라오지 못하면 고정 댓글 첫 줄을 "구글폼 인증까지 해야 완료"로 바꾼다 |
| 10/6(화) 1차 | 첫 1주 퍼널 | 3단계 이탈률이 높으면 10/6~10/7 게시물을 '인증 안내' 중심으로 유지. 인증 유효율이 낮으면 캡처 예시 카드를 추가 제작 요청(디자인 팀) |
| 10/13(화) 2차 | 마감 전 퍼널 | D-1 메시지를 '체크리스트' 형식으로 확정(현 초안) |
| 10/16 이후 | 최종 정리 | 채널별 유입(YouTube 스튜디오 '트래픽 소스'의 외부 유입), 지역센터 공유 효과, 다음 이벤트 개선점 |

- 목표치는 기준값(현재 구독자 수, M/V 평균 조회수)을 확인한 뒤 정한다 `[확인 필요]`. 이 문서에는 임의 목표 수치를 넣지 않았다.
- 원문 링크만 쓰므로 링크별 UTM 추적은 하지 않는다. 채널별 기여는 각 플랫폼 인사이트의 링크 클릭 수와 YouTube 스튜디오 외부 트래픽 소스로 비교한다.

## 8. 참여 장치 설계 원칙 (개인정보 최소 수집)

- 이 기간에는 **원문 이벤트 외 별도 경품 이벤트를 만들지 않는다.** 혜택·조건을 덧붙이지 않는다.
- SNS 채널에서는 어떤 개인정보도 따로 받지 않는다. 응모 정보는 원문의 구글폼으로만 받는다.
- 인스타그램 스토리 질문 스티커 등 보조 참여 장치는 "언제 행복하세요?"처럼 개인정보와 무관한 질문만 쓰고, 답변을 공유할 때는 계정명을 가린다.
- 참여자 댓글·캡처를 2차 콘텐츠로 쓰려면 작성자 동의를 받는다. 동의 전에는 계정명 없는 주제 요약만 쓴다.
- 아동·청소년으로 보이는 참여자의 댓글은 2차 활용하지 않는다.
