# my-project
# 자봉이의 동네 구하기

작은 행동이 모이면 우리 동네가 달라져요! 청소년과 시민을 위한 약 2~3분의 모바일 웹 자원봉사 미니게임입니다. GitHub에 업로드된 자봉이 3D 원본을 시작·결과 화면 및 저장 PNG에 적용했습니다.


## 자원봉사자 메이커 — 별도의 육성 RPG

**`maker.html`**에서 「자원봉사자 메이커 — 자봉이의 첫 4주」를 플레이합니다. 기존 점프 게임은 기본 주소에 유지하고 하단에 RPG 링크를 추가했습니다.

- 총 4주, 주마다 3칸의 일정으로 12번의 하루를 보냅니다. 활동 8종(응급 교육·소통·공원 정화·그림책·나눔 꾸러미·행사 지원·이웃 동행·휴식)을 순서대로 배치하고 한 주를 시작합니다.
- 공감·실행·협력·체력이 선택에 따라 변합니다. 체력이 부족한 일정은 휴식으로 조정하며, 다음 주에는 체력 15를 회복합니다. 휴식과 활동의 균형을 계획할 수 있습니다.
- 기술 6종과 특성 4종을 조건에 따라 배웁니다. 배운 기술은 사건의 추가 선택지를 엽니다. 미습득 선택지는 필요한 기술을 표시하고 잠깁니다.
- 사건 12종을 활동·반복 횟수·인연에 따라 선택합니다. 이웃 4명과 인연을 쌓으면 각자의 후속 이야기가 열립니다. 선택의 결과는 활동 일지에 남습니다.
- 방에 화분·책·안전 파우치·감사 카드·축제 깃발이 생기고, 마지막 프로젝트의 소품도 놓입니다. 제공된 투명 자봉이 모션 시트의 정면 프레임을 사용합니다.
- 마지막에는 초록길·안심 동행·나눔 축제·그림책 오후 중 하나를 선택합니다. 기술·핵심 능력·인연·체력에 따라 첫걸음/준비된 실천/함께 피운 결실의 세 표현으로 엔딩이 달라집니다. 준비가 덜 되어도 소규모 체험으로 마칠 수 있으며, 네 프로젝트 엔딩을 도감에 모읍니다.
- 결과 PNG 저장·게임 링크 공유·1365 링크와 다시 키우기를 제공합니다. 회원가입·서버·외부 API가 필요 없습니다.

### 저장과 수정

매 선택 직후 `jabongi-maker-save`에 현재 주·일정·사건·피드백·능력치·기술·일지를 저장합니다. 다시 열면 시작 화면에서 이어 키울 수 있습니다. 엔딩 도감은 `jabongi-maker-endings`에 따로 저장하므로 새로 키워도 유지합니다. 저장소가 제한되어도 현재 창에서 끝까지 플레이할 수 있습니다. 소리 설정은 기존 `jabongi-sound`를 공유합니다. 초기화하려면 각 게임의 해당 LocalStorage 키만 삭제하세요.

`src/maker-data.js`: 활동, 이웃, 사건과 선택 효과, 기술 조건, 프로젝트 요구 능력.
`src/maker-engine.js`: 4주 흐름, 능력·체력, 기술·특성·인연 해금, 엔딩, 저장 데이터 검증.
`src/maker-art.js`: 방과 성장 소품, 활동 장소, 이웃 초상화 SVG.
`src/maker.js`: 반응형 화면, 일정 조작, 자동 저장·재개, 일지·도감, PNG·공유.
`src/maker.css`: 육성 게임 UI 및 모바일 배치.

`tests/maker-engine.test.js`는 네 특화 엔딩, 기술 선택지·중복 보상 방지·체력·후속 사건·저장 복구를 검증합니다. `tests/maker.spec.js`는 모바일·PC에서 4주 플레이·엔딩·PNG·공유·일지·도감·저장 재개·기술 잠금·320px·저장소 차단을 검증합니다. 실행과 배포 명령은 기존과 같습니다.

## 작은 동네의 모험 — 가로 스크롤 점프 게임

기본 화면은 자봉이를 **좌우로 직접 조작하는 가로 스크롤 플랫폼 모험**입니다. 초록 공원 → 나눔 골목 → 별빛 이웃 마을의 세 코스를 탐험하고 각 목적지 깃발에 도착하면 다음 동네로 이동합니다. 이전 러너는 `retro.html`, 세 미션은 `classic.html`에 보관되어 있습니다.

- PC: ←/→ 또는 A/D 이동, Space/↑/W 점프, Esc/P 일시정지. 점프 키를 길게 누르면 높게, 일찍 떼면 낮게 뜁니다.
- 모바일: 방향 버튼을 **누르고 있는 동안** 이동합니다. 이동 버튼을 누른 채 JUMP를 함께 누를 수 있습니다. 화면을 길게 눌러 점프할 수도 있습니다.
- 초록 발판 위로 올라가고, 틈을 넘어 이동합니다. 각 스테이지는 실제 물리로 완주 가능한 경로를 테스트합니다.
- 금색 나눔 블록을 아래에서 치면 한 번에 50점, 하트 온기는 10점, 초록 실천은 20점, 먼지를 위에서 밟으면 30점, 목적지 도착은 100점입니다.
- 먼지 몬스터에 옆에서 닿거나 틈에 떨어지면 하트가 하나 줄어듭니다. 충돌 뒤 1.65초 동안 추가 접촉 피해를 막습니다. 틈에서 떨어졌을 때는 마지막 중간 깃발에서 다시 출발하며 이미 모은 점수와 아이템 상태는 유지합니다.
- 하트가 0이 되면 결과를 표시합니다. 각 동네 완료 후 다음 동네에 출발하면 하트 하나를 충전합니다(최대 3개).
- 시간제한이 없어 천천히 탐험할 수 있습니다. 조작 숙련도와 재도전에 따라 플레이 시간이 달라집니다. 발판 가장자리 점프 허용 0.11초와 입력 버퍼 0.14초로 조작 여유를 줍니다.
- 최고 기록은 `jabongi-adventure-best`에 별도로 저장합니다. 결과 PNG와 링크 공유, 자원봉사 찾기를 제공합니다. 다른 탭으로 이동하면 자동 일시정지합니다.
- 투명 배경 자봉이 `jabongi-clean.png`를 그대로 사용합니다. 타 게임의 캐릭터·지형·음악 파일은 사용하지 않습니다.

### 아이템 진화 — 기본 → 든든 → 꽃빛 자봉이

길에 놓인 **성장 하트**를 먹으면 든든 자봉이가 되어 시각적인 몸집이 20% 커지고 한 번의 접촉 피해를 진화 단계로 막습니다. **나눔 꽃**을 먹으면 꽃빛 자봉이가 되어 꽃빛 입자와 함께 정화 하트를 발사할 수 있습니다. 꽃을 먼저 먹어도 바로 꽃빛 단계가 됩니다. 공식 캐릭터의 이미지 디자인·종횡비는 유지하며, 커진 모습이 기존 통로를 막지 않도록 몸통 판정은 유지합니다.

- 발사: PC **X/F**, 모바일 **♡ 발사 버튼**. 누르고 있으면 재사용 대기시간에 맞춰 연속 발사합니다.
- 정화 하트는 먼지 한 마리를 정화하고 30점을 주며, 블록에 닿으면 사라집니다. 이웃·집·미션에는 피해를 주지 않습니다. 최대 동시 3개, 대기시간 0.38초, 수명 1.3초입니다.
- 접촉 피해는 보호막 → 꽃빛에서 든든 → 든든에서 기본 → 기본 상태의 하트 감소 순서로 처리합니다. 단계를 잃은 뒤 1.65초의 무적 시간을 줍니다.
- 구멍에 떨어지면 하트가 줄고 기본 단계로 돌아가지만, 남은 길의 아이템으로 다시 강화할 수 있습니다. 다음 동네로 정상 이동할 때는 진화를 유지하며 날아가는 하트는 정리합니다.
- 이미 가진 단계의 아이템은 약한 단계로 낮추지 않고 30점의 추가 보너스를 줍니다. 각 동네의 앞쪽과 중간 이후에 재보충 아이템을 배치했습니다.
- 화면에는 현재 단계와 발사 안내를 표시하고, 결과에는 최고 진화와 정화 하트 성공 횟수를 남깁니다.

`src/platform-powerups.js`가 진화·연속 발사·정화 판정을 담당합니다. `tests/platform-powerups.test.js`는 획득·피해·중복·발사 상한·충돌·정지·단계 유지를 검증하고, `tests/platform-powerups.spec.js`는 실제 이동으로 두 아이템을 먹고 모바일·PC에서 발사·정화를 검증합니다.

### 스토리와 플레이 동작 보강

현재 기본 모험은 각 동네의 부탁을 완료해야 깃발에서 다음 동네로 이동할 수 있습니다.

1. **공원 되살리기:** 길의 쓰레기 3개 이상을 모으고, 끝부분 공원 지킴이에게 가까이 가서 분리배출 방법을 선택합니다. 추가 쓰레기도 점수로 보상합니다.
2. **세 집에 나눔 전달:** 공부·생활·간식 꾸러미를 찾아 필요한 세 집에 각각 전달합니다. 집마다 필요한 꾸러미가 다르며 전달하면 집의 창문이 밝아집니다.
3. **이웃의 마음 듣기:** 짐을 든 이웃에게 먼저 물어보고, 도움을 사양한 이웃을 존중하고, 길을 찾는 이웃에게 원하는 도움을 제안합니다. 성공할 때마다 가로등이 켜집니다.

가까운 이웃은 **E** 또는 화면의 **대화 버튼**으로 상호작용합니다. 대화 중에는 물리와 시간이 멈추며 오답은 힌트 후 재선택할 수 있습니다. 물품이 부족하거나 목적지에서 미션이 남아 있으면 방향 힌트를 표시합니다. 배달과 대화는 한 번만 점수를 줍니다.

각 동네에는 높은 경로의 **숨은 별 3개**, 자동으로 높이 튀어 오르는 **스프링**, **12초간 충돌 한 번을 막는 보호막**이 있습니다. 나눔 골목에는 타고 이동할 수 있는 움직이는 발판도 있습니다. 별은 선택 목표이고, 동네를 마치면 고유 배지와 별 성적을 표시합니다. 체크포인트 재시작 시 완료한 부탁·수집품은 유지합니다.

캐릭터는 정면의 얼굴·가슴이 보이는 오른쪽 3/4 방향 대기·걷기 두 프레임·점프를 담은 **2×2 RGBA 스프라이트** `assets/characters/jabongi-front-motion.png`를 사용합니다. 오른쪽 이동은 원래 프레임, 왼쪽 이동은 프레임을 좌우 반전하여 진행 방향을 맞춥니다. 시작 화면도 대기 프레임으로 바꿨습니다. 기존 공식 원본은 보관하며, 새 포즈는 제공된 디자인을 참고해 Image Gen으로 생성한 게임용 파생 이미지입니다.

동네별 목표·이웃·대화·꾸러미·숨은 별은 `src/platform-missions.js`에서 수정합니다. `tests/platform-missions.test.js`가 미션·일회성 보상·보호막·발판을, `tests/platform-story.spec.js`가 **실제 키 입력과 대화 선택으로 세 동네를 완주**하고 배지를 얻는 흐름·이동 방향·포즈·투명도를 검증합니다.

### 모험 버전 구조와 검증

`src/platform-engine.js`는 스테이지 데이터, 중력·충돌·점프 높이·아이템·깃발·체크포인트를 담당합니다. `src/platform-renderer.js`는 구름·마을의 시차 이동, 입체 블록, 먼지, 깃발과 투명 캐릭터를 Canvas로 그립니다. `src/platform.js`는 입력·화면·모바일 멀티터치·카메라·소리·결과 저장을 연결하고 `src/platform.css`는 반응형 UI를 정의합니다.

`tests/platform-engine.test.js`는 착지·머리 충돌·단발 보너스·짧은 점프·밟기·피해·체크포인트·세 동네 완주를 확인합니다. `tests/platform.spec.js`는 실제 브라우저의 이동·점프·일시정지·게임오버·PNG·재도전·멀티터치·320px 화면을 검증합니다. 기존 러너·미션·투명도 검사도 유지합니다.

## RETRO RUN — 러너 버전

`retro.html`은 **3D 카툰 자봉이 + 레트로 노을 배경의 3레인 러너**입니다. 기존 세 가지 미션은 `classic.html`에서 계속 플레이할 수 있습니다.

- 모바일: 좌우 스와이프 또는 아래 화살표 버튼으로 이동, 화면 탭·위 스와이프·JUMP 버튼으로 점프.
- PC: ←/→ 또는 A/D로 이동, Space/↑로 점프, Esc/P 또는 Ⅱ 버튼으로 일시정지.
- 2분 동안 달리면 완주합니다. 하트는 3개이며, 장애물은 레인을 바꾸거나 점프로 피합니다. 점프는 착지한 뒤 다시 할 수 있습니다.
- 온기 코인과 쓰레기 수거는 기본 10점. 연속 8개마다 배수가 올라가며 최대 5배입니다. 충돌하면 현재 콤보가 끊깁니다. 장애물을 뛰어넘으면 5점 보너스를 받습니다.
- 보호막은 10초 이내의 충돌 한 번을 막고, 자석은 9초 동안 옆 레인의 아이템도 모읍니다.
- 40초마다 노을빛 골목 → 나눔의 거리 → 온기 가득한 밤으로 바뀌며 속도가 점차 빨라집니다. 처음 7초 동안 생성되는 줄에는 장애물이 없습니다.
- 한 줄에 장애물은 한 레인만 차지하도록 생성하므로 피할 길이 있습니다. 아이템은 안전한 레인으로 안내합니다.
- 결과 화면에서 점수·거리·최고 콤보·온기, 기록 PNG 저장, 링크 공유, 재도전 및 1365 링크를 제공합니다. 온기는 수집 30개에 100%입니다.
- 러너 최고 점수는 `jabongi-runner-best`로 별도 저장하며 기존 미션 최고 점수는 유지합니다. 다른 탭으로 이동하면 자동 일시정지합니다.

### 러너 파일

`src/runner.js`: 러너 UI·입력·오디오·결과·공유. `src/runner-engine.js`: 독립된 물리·레인·충돌·점수·아이템 규칙. `src/runner-renderer.js`: Canvas 2D를 이용한 원근감 있는 2.5D 도로, 입체 건물·장애물, 레트로 일몰과 배경 이동. 실제 3D 모델/WebGL 엔진은 사용하지 않으며, 자봉이는 제공된 3D 렌더링 이미지입니다. `src/runner.css`와 `src/style-base-runner.css`: 반응형 게임 UI.

`assets/characters/jabongi-runner.png`는 최초 배경 제거 파생 파일이며, 현재 사용하는 `jabongi-clean.png`는 외곽 잔여물을 추가 정리한 투명 RGBA 파일입니다. 두 파일 모두 제공된 점프 포즈 `jabongi-10.png`에서 배경 제거만 요청해 Image Gen으로 만든 파생 파일입니다. 원본 PNG 12개는 편집·삭제하지 않았습니다. 원본 디자인과 비율을 유지하도록 요청했으며, 게시 전 권리자 관점의 최종 확인이 가능합니다.

`tests/runner-engine.test.js`는 이동 경계·점프·충돌·무적·보호막·자석·콤보·안전 경로·2분 완주를 검증합니다. `tests/runner.spec.js`는 모바일·PC에서 실제 조작·일시정지·게임오버·재도전·PNG·320px 화면·저장소 차단을 검증합니다. 기존 미션 테스트도 함께 실행합니다.

아래의 세 미션·300점 설명은 **차근차근 미션 모드(`classic.html`)**에 해당합니다.

## 실행

Node.js 22 이상에서:

```sh
npm ci
npm run dev
```

표시되는 로컬 주소를 브라우저에서 엽니다. 같은 네트워크의 모바일에서는 터미널의 Network 주소로 접속합니다. 모듈을 사용하므로 `index.html`을 파일로 직접 열지 말고 개발 서버를 이용하세요.

```sh
npm test       # 점수 규칙 테스트
npm run build # 배포용 dist 생성

```

src/art.js                 원본 SVG 마을과 임시 도형

터치 선택 중심인 이번 버전은 Phaser 대신 기본 DOM/SVG로 구현했습니다. 무거운 게임 엔진 다운로드 없이 실행되며 버튼의 키보드 조작과 스크린리더 설명을 제공합니다. 런타임 외부 API, CDN, 폰트, 서버, DB가 필요하지 않습니다. 개발·빌드 도구는 Vite입니다.

## 플레이 및 점수

시작 → 마을 지도 → 원하는 미션 선택 → 미션 완료 → 지도 → 세 미션 완료 → 최종 결과. 미션 순서는 자유이며 같은 도전에서 완료한 미션은 다시 점수를 주지 않습니다. 결과 화면의 다시 도전으로 모두 초기화합니다.

- LEVEL 1: 쓰레기 6개 수거, 목표 35초. 마지막 수거 후 밝은 마을과 완료 효과를 표시합니다.
- LEVEL 2: 물건 선택 후 공부/생활 상자 선택. 오답은 힌트를 제공하고 재시도하며 목표 40초입니다.
- LEVEL 1·2: 수행 6×10점 + 완료 20점 + 콤보 최대 10점 + 속도 최대 10점. 4초 이내 연속 성공마다 콤보 2점, 한 미션 내 최고 연속 기록을 반영합니다. 오답은 현재 연속 기록을 끊습니다. 속도 = `max(0, round(10 × (1 - 경과초 / 목표초)))`이며 시간 초과는 속도 0점, 게임오버가 아닙니다.
- LEVEL 3: 먼저 의사 묻기, 거절 존중, 원하는 도움 제안하기의 세 문항. 정답에 이를 때까지 힌트와 재도전, 각 정답 20점 + 완료 40점. 시간제한 없습니다.
- 총점 300점, 온기는 완료한 미션에 따라 0 → 33 → 67 → 100%입니다.
- 잠시 쉬기 또는 다른 탭으로 이동 시 시간이 멈춥니다. 진행 중 페이지를 새로고침하면 이번 도전은 초기화됩니다.
- LocalStorage에는 최고 점수(`jabongi-best`)와 소리 설정(`jabongi-sound`)만 저장합니다. 저장소가 차단되어도 게임을 할 수 있습니다. 소리는 기본 OFF이며 사용자 조작 이후 Web Audio로 재생합니다.

## 공식 이미지와 내용 수정

업로드된 원본 12개는 `assets/characters/jabongi-01.png`~`jabongi-12.png`로 편집 없이 보관합니다. `sources.json`에서 GitHub 원본 파일명과의 대응을 확인할 수 있습니다. 업로드된 원본은 RGB여서 투명도 채널이 없으며, 일부 체크무늬도 원본 픽셀에 포함되어 있습니다. 현재 두 게임 모드는 배경과 외곽 잔여물을 정리한 RGBA 파생 파일 `jabongi-clean.png`를 사용합니다. 캐릭터 이미지에는 흰 배경이나 사각형 그림자를 적용하지 않습니다. 원본 12개는 편집 없이 보관합니다.

다른 공식 파일을 `assets/characters/`에 넣고 `src/config.js`의 `CHARACTER_PATH`를 파일명으로 지정합니다. 원본 비율을 유지해 시작·결과 화면과 결과 PNG에 표시하며 원본을 변형하지 않습니다. 경로가 잘못되면 임시 도형을 유지합니다. Windows PC의 폴더 경로는 웹/클라우드에서 직접 접근할 수 없으므로 파일 자체를 저장소에 추가해야 합니다.

미션 문구/분류/이웃 선택지는 `src/config.js`, 점수는 `src/scoring.js`, 색상/배치는 `src/style.css`에서 수정합니다. 물건 수와 문항 수를 바꾸려면 점수와 진행 표시도 함께 수정하세요. 이모지 아이템은 운영체제에 따라 외형이 달라집니다.

## 결과 저장 및 공유

최종 점수와 마을, 캐릭터를 Canvas로 그려 PNG 다운로드를 제공합니다. 모바일 브라우저에서 자동 저장이 안 되면 표시되는 다운로드 링크를 이용합니다. 네이티브 공유가 있으면 공유 창을 열고, 없으면 게임 주소를 복사합니다. 클립보드도 사용할 수 없으면 선택 가능한 주소 입력창을 표시합니다. `1365` 버튼은 새 탭에서 공식 자원봉사 포털을 엽니다.

## GitHub Pages 배포

1. GitHub 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다.
2. 코드를 main 브랜치에 반영하거나 Actions의 `Deploy game to GitHub Pages`를 수동 실행합니다.
3. 작업이 완료되면 Pages에 표시되는 주소에서 플레이합니다. 이 저장소라면 일반적인 주소는 `https://handssumboy-oss.github.io/my-project/`입니다(배포 설정에 따라 다름).

`vite.config.js`의 `base: './'`로 빌드된 CSS/JS/이미지를 상대 경로로 로드하므로 저장소 하위 경로에서도 동작합니다. 소스가 아닌 **dist**를 배포합니다. GitHub Pages 도메인과 HTTPS 환경에서 공유 기능을 확인하세요. 이 작업에는 배포 설정 파일이 포함되며 원격 게시 실행 여부는 별도 확인이 필요합니다.

## 브라우저 검증

```sh
npx playwright install chromium
npm run test:e2e
```

테스트 설정은 `/usr/bin/chromium`이 있으면 사용하고, 없으면 Playwright 설치 브라우저를 사용합니다. 별도 브라우저는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 환경변수로 지정할 수 있습니다. 배포 워크플로에서도 브라우저를 설치하고 전체 플레이 테스트를 실행합니다.
