# daily/ — 홍보팀 자동 작업 결과

예약 실행(Routine)이 매일 이 폴더에 결과물을 저장한다. 사람은 결과를 확인하고 직접 게시한다.

## 폴더 구조
- `업무메모.md`: 담당자가 센터 업무 진행 상황을 한두 줄씩 적는 곳 (저녁 게시물 재료)
- `YYYY-MM-DD/`: 날짜별 결과물
  - `00_브리핑.md`: 오늘의 D-day, 일정, 뉴스 모니터링, 리스크, 확인 필요 사항
  - `01_아침_후킹.md`: 08:00 게시용 (관심 끌기)
  - `02_점심_정보.md`: 12:00 게시용 (자원봉사 정보·통계·참여 방법)
  - `03_저녁_센터업무.md`: 19:00 게시용 (센터가 한 일 소개)
- `weekly/YYYY-Www.md`: 주간 콘텐츠 기획과 다가오는 기념일 준비

## 게시 방법 (권장)
매일 아침 결과를 확인한 뒤, Meta Business Suite(인스타그램·페이스북) 예약 게시로 3건을 한 번에 예약한다.
AI는 게시하지 않는다. 최종 게시 전 사람이 반드시 확인한다.
